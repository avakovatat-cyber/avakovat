# 🤖 Telegram Бот для выдачи гайда после подписки

## 📦 Что внутри:
- Проверка подписки на канал @nabase_money
- Автоматическая выдача ссылки на Google Docs гайд
- Готов к деплою на Railway

---

## 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ НА RAILWAY:

### Шаг 1: Регистрация на Railway
1. Перейдите на https://railway.app/
2. Нажмите **"Login"** → войдите через GitHub
3. Если нет GitHub - создайте аккаунт (быстро, бесплатно)

### Шаг 2: Создание проекта
1. После входа нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Нажмите **"Configure GitHub App"**
4. Разрешите доступ Railway к вашему GitHub

### Шаг 3: Загрузка файлов на GitHub
1. Перейдите на https://github.com/new
2. Придумайте название репозитория (например: `telegram-guide-bot`)
3. Нажмите **"Create repository"**
4. На странице нового репозитория нажмите **"uploading an existing file"**
5. Загрузите все 4 файла из папки telegram_bot:
   - bot.py
   - requirements.txt
   - Procfile
   - runtime.txt
6. Нажмите **"Commit changes"**

### Шаг 4: Деплой на Railway
1. Вернитесь на Railway → **"New Project"** → **"Deploy from GitHub repo"**
2. Выберите только что созданный репозиторий
3. Railway автоматически начнёт деплой
4. Подождите 1-2 минуты пока бот запустится

### Шаг 5: Проверка
1. В Railway увидите зелёную галочку ✅
2. Зайдите в логи (вкладка "Deployments" → последний деплой → "View Logs")
3. Должна быть строка: **"✅ Бот успешно запущен!"**
4. Напишите боту в Telegram /start - должен ответить!

## ✏️ КАК ВНОСИТЬ ИЗМЕНЕНИЯ:

### Изменить тексты сообщений:
1. Зайдите в ваш GitHub репозиторий
2. Откройте файл `bot.py`
3. Нажмите на значок карандаша (редактировать)
4. Найдите нужный текст и измените его
5. Нажмите **"Commit changes"**
6. Railway автоматически перезапустит бота с новыми изменениями!

### Что можно легко менять в bot.py:
```python
# Приветственное сообщение (строки 26-29)
"👋 Привет!\n\n"
"Чтобы получить бесплатный гайд, подпишись на наш канал и нажми кнопку проверки:"

# Сообщение при успешной подписке (строки 36-39)
f"🎉 Отлично! Ты подписан!\n\n"
f"Вот твой гайд:\n{GUIDE_LINK}\n\n"
f"Приятного чтения! 📚"

# Сообщение если не подписан (строка 45)
"❌ Ты ещё не подписан на канал! Подпишись и нажми кнопку снова."
```

## 🔧 ЕСЛИ ЧТО-ТО ПОШЛО НE ТАК:

**Бот не отвечает?**
- Проверьте логи в Railway (там будет ошибка)
- Убедитесь что бот добавлен в администраторы канала

**Не работает проверка подписки?**
- Бот должен быть администратором канала @nabase_money
- ID канала должен быть правильный: -1003945323384

**Railway просит оплату?**
- Бесплатный лимит: 500 часов работы в месяц (хватает с запасом!)
- Если закончится - придёт письмо, можно будет добавить карту
